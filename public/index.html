⚠ Seeing a security warning in your browser?
Your browser doesn't trust this server's self-signed certificate yet. Run the AnyCert client script on your machine to automatically install the Root CA and permanently eliminate all HTTPS browser warnings:
⬇ Windows (.bat) ⬇ Linux (.sh) ⬇ macOS (.sh)
Windows: Right-click anycert-windows.bat → Run as Administrator
Linux: Open terminal and run sudo bash anycert-linux.sh
macOS: Open terminal and run sudo bash anycert-macos.sh
💡 Tip: After running the script, please completely restart your browser (or open a new Incognito window) to apply the trusted Root CA certificate and enable the 🔒 HTTPS secure connection.
