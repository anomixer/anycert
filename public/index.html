⚠ 瀏覽器出現不安全連線警告？ ⚠ Seeing a security warning in your browser?
這是因為客戶端電腦尚未信任此伺服器的自簽 Root CA 憑證。請執行下方的 AnyCert 用戶端一鍵腳本，自動匯入 CA 憑證並徹底消除所有 HTTPS 警告訊息： Your browser doesn't trust this server's self-signed certificate yet. Run the AnyCert client script on your machine to automatically install the Root CA and permanently eliminate all HTTPS browser warnings:
⬇ Windows (.bat) ⬇ Linux (.sh) ⬇ macOS (.sh)
Windows: 右鍵點選 anycert-windows.bat → 以系統管理員身分執行 Right-click anycert-windows.bat → Run as Administrator
Linux: 開啟終端機並執行 sudo bash anycert-linux.sh Open terminal and run sudo bash anycert-linux.sh
macOS: 開啟終端機並執行 sudo bash anycert-macos.sh Open terminal and run sudo bash anycert-macos.sh
💡 提示： 執行完腳本後，請完全關閉並重開瀏覽器（或開啟無痕視窗），即可套用受信任的 Root CA 憑證並開啟 🔒 HTTPS 安全連線。 💡 Tip: After running the script, please completely restart your browser (or open a new Incognito window) to apply the trusted Root CA certificate and enable the 🔒 HTTPS secure connection.
